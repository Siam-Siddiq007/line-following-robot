# Hardware

This directory contains the hardware documentation for the line following robot.

It will include the electronics architecture, motor driver, sensors, power system, battery configuration, and mechanical components.

## Main Components

- ESP32 DevKitC
- TB6612FNG motor driver
- 2 × N20 6V 500RPM gear motors
- 43mm rubber wheels
- 8-channel line sensor
- 2S Li-ion battery
- 2S Li-ion BMS
- 6V buck converter for motors
- 5V buck converter for ESP32
- Carbon-fiber sensor boom
- Front ball caster
